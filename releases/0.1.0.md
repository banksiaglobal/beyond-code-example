# 0.1.0 — baseline payment flow

The first IRIS source baseline describes:

- order creation and lookup;
- basic payment initiation through the local gateway simulator;
- successful provider confirmation that makes the order paid;
- protection against intentionally paying an already paid order again.

Runtime behaviour was not verified in this demonstration step. The source intentionally covers only the normal successful provider sequence; other provider outcomes and unusual event sequences remain outside this release's scope.
